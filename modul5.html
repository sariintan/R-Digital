Modul 5 — Waspada Hoaks, Link Palsu, dan Malware

Belajar mengenali pesan mencurigakan dan menjaga keamanan perangkat

Tujuan Modul

  • mengenali ciri-ciri hoaks,
  • memahami bahaya link palsu dan malware,
  • mengetahui langkah aman saat menerima pesan mencurigakan.

A. Apa Itu Hoaks?

Hoaks adalah informasi bohong, tidak benar, atau menyesatkan yang dibuat agar orang lain percaya dan menyebarkannya.

Hoaks sering muncul dalam bentuk:

  • pesan berantai,
  • berita sensasional,
  • video lama yang dibagikan ulang,
  • informasi kesehatan palsu,
  • promo atau hadiah palsu.

B. Ciri-Ciri Hoaks

Waspadai pesan yang:

  • judulnya sangat heboh,
  • membuat panik atau marah,
  • sumbernya tidak jelas,
  • memaksa untuk segera disebarkan,
  • menggunakan kata-kata berlebihan,
  • tidak ada bukti yang kuat.

C. Apa Itu Link Palsu?

Link palsu adalah tautan yang dibuat untuk:

  • mencuri data,
  • mengambil akun,
  • menipu pengguna,
  • memasang aplikasi berbahaya.

Contoh modus:

  • “Paket Anda tertahan, klik di sini”
  • “Undangan digital, buka file ini”
  • “Menang hadiah, isi data sekarang”
  • “Bantuan dana cair, klik link”

D. Apa Itu Malware?

Malware adalah program berbahaya yang bisa masuk ke HP atau perangkat kita.

Malware bisa membuat:

  • HP lemot,
  • data dicuri,
  • akun dibobol,
  • iklan aneh muncul terus,
  • aplikasi berjalan tanpa izin.

E. Cara Aman Menghadapi Pesan Mencurigakan

Jangan lakukan:

  • jangan klik link sembarangan,
  • jangan unduh file dari nomor tak dikenal,
  • jangan instal aplikasi dari chat,
  • jangan masukkan data pribadi ke link aneh,
  • jangan berikan OTP.

Lakukan:

  • cek pengirim,
  • baca link dengan teliti,
  • tanya ke orang terpercaya,
  • cari info pembanding,
  • hapus dan blokir jika mencurigakan.

F. Contoh Kasus

Kasus: Ibu menerima pesan: “Undangan pernikahan digital. Klik file APK ini untuk melihat undangan.” Karena penasaran, file dibuka dan diinstal.

Akibatnya: HP terkena aplikasi berbahaya dan akun bisa disalahgunakan.

Pelajaran: Jangan instal file dari chat, terutama file yang tidak jelas asalnya.

G. Tips Praktis

  • Jika terlalu bagus untuk dipercaya, biasanya perlu dicurigai.
  • Jangan tergesa-gesa klik link.
  • Gunakan aplikasi resmi dari Play Store/App Store.
  • Periksa nama website dengan teliti.
  • Jika ragu, lebih baik abaikan.

H. Yang Boleh dan Tidak Boleh

Boleh:

  • ✅ Cek dulu sebelum klik
  • ✅ Bertanya jika ragu
  • ✅ Hapus pesan mencurigakan
  • ✅ Blokir nomor penipu

Tidak Boleh:

  • ❌ Klik link sembarangan
  • ❌ Instal file dari chat
  • ❌ Isi data pribadi di situs mencurigakan
  • ❌ Memberikan OTP
